# Heart Disease Prediction

## Project Overview
This is a Machine Learning project designed to predict the likelihood of heart disease in patients based on clinical parameters. The model is built using Python and the Scikit-learn library.

## Repository Contents
* `HEART.ipynb` - Jupyter Notebook containing data preprocessing, exploratory data analysis (EDA), and model training.
* `PBL_Report.pdf` - (Coming Soon) Final project report detailing methodology and results.

## Technologies Used
* Python
* Scikit-learn
* Pandas & NumPy
* Matplotlib & Seaborn
